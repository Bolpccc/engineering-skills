# Repository Rules

- `skills-manifest.json` is the catalog and dependency source of truth.
- Keep Design and Build authority separate even when a change affects both.
- Domain Skills own facts, status, safety, interfaces, and persistence.
- `cognitive-bridge` may organize an explanation but may not change engineering meaning.
- Update affected behavior scenarios with every consequential instruction change.
- Run `python3 scripts/validate.py` before committing.
- Do not add submodules, generated installed copies, credentials, or private project evidence.
